# robshare-media

316 WebP images for 22 Robshare robots. `robots.json` is the map: `hero` is the key image, `images` is the gallery.

`https://cdn.jsdelivr.net/gh/dxnielleadpages/robshare-media@v2/{slug}/hero.webp`

Full-size originals for Figma are not in this repo.

## Logo

| File | Use on |
| --- | --- |
| `logo/robshare-logo-on-light.svg` | Light surfaces (white, mist). Wordmark in `#2E3130`. |
| `logo/robshare-logo-on-dark.svg` | Dark surfaces (night `#101312`). Wordmark in white. |
