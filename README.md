# robshare-media

316 WebP images for 22 Robshare robots. `robots.json` is the map: `hero` is the key image, `images` is the gallery.

After this repo is public and tagged `v1`:

`https://cdn.jsdelivr.net/gh/dxnielleadpages/robshare-media@v1/{slug}/hero.webp`

The files are not on the CDN yet (`published` in `robots.json` is false). Full-size originals for Figma are not in this repo.
